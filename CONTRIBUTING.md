# Contributing

Thanks for your interest in MagicalGirlWebOracle. This project is developed and
tested primarily against Python 3.12.

## Development setup

```bash
git clone https://github.com/LingMoe404/MagicalGirlWebOracle.git
cd MagicalGirlWebOracle
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env      # optional; tests do not need real keys
```

Run the test suite:

```bash
python -m pytest
```

The default suite is fully mocked and needs no API keys or network access. A
few tests are marked `LIVE=1`-gated and are skipped by default.

## Frontend

The admin bundle is generated by Vite and committed to
`src/magicalgirl_web_oracle/admin/static/`:

```bash
cd frontend
npm ci
npm run build
```

Vite writes directly into the package's static directory. If you change
frontend source, rebuild and include the generated files in your commit.

## Code style

- Keep changes focused and add a regression test for bug fixes.
- Follow the existing structure and naming; avoid new dependencies unless they
  are clearly necessary.
- Do not commit `.env`, `data/`, API keys, private keys, or real usage ledgers.
- Keep user-facing text in the existing tone and language (Chinese admin UI,
  English code comments where the surrounding code is English).

## Pull requests

1. Describe the problem and the approach.
2. Include tests and the commands you ran.
3. Note any behavior, configuration, or security-default changes.
4. Update `CHANGELOG.md` for user-visible changes.
5. Make sure CI passes.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
